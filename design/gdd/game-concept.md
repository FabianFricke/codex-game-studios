# Game Concept: Retro Hop

## Elevator Pitch

Retro Hop is a one-level original 2D platformer where a nimble character
crosses a bright obstacle course built around crisp jumping, readable hazards,
and optional gem collection.

## Genre

Side-scrolling platformer.

## Session Length

- First clear: three to six minutes.
- Replay clear: one to two minutes.

## Target Feel

Immediate, fair, readable, and cheerful.

## Core Verbs

- Run
- Jump
- Land
- Stomp
- Collect
- Finish

## Production Promise

The game is small, but it is complete within its chosen scope: one readable
level, one movement kit, one collectible, one hazard type, one finish.
