# Studio Templates

Use these templates to create consistent artifacts that both humans and agents
can navigate quickly.

## Recommended Use

- Start from the smallest template that matches the task.
- Keep filled-in documents concrete and decision-oriented.
- Link related docs rather than duplicating large sections.
- When a workflow asks for a specific output, use the matching template here.

## Common Templates

- `game-concept.md`
- `game-pillars.md`
- `game-design-document.md`
- `technical-design-document.md`
- `architecture-decision-record.md`
- `sprint-plan.md`
- `milestone-definition.md`
- `test-plan.md`
- `post-mortem.md`
