# Studio Standards

These files define review expectations for different domains of work.

## How To Use Standards

- Read the relevant standard before making changes in that area.
- Use the checklist during review, not just after the work is done.
- If a standard no longer fits the repo, update the standard and the workflow
  that depends on it in the same change.
