# Studio Roles

These files define the specialist roles for the game studio model.

## How To Use Roles In Codex

- Choose the role that would own the task in a real studio.
- Use the role file as a reasoning and review frame.
- Follow its responsibilities and constraints, but adapt execution to the
  studio workflows and available tools.
- Delegate only when the task actually benefits from parallelism.

## Common Starting Points

- `creative-director.md` for vision and design alignment
- `technical-director.md` for architecture and engine direction
- `producer.md` for planning, sequencing, and delivery
- `lead-programmer.md` for code structure and technical review
- `game-designer.md` for systems and mechanics design
- `qa-lead.md` for quality strategy and verification
