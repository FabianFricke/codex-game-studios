# Project Center: Retro Hop

## Status

Active production.

Retro Hop is a one-level original side-scrolling platformer built around crisp
movement, readable obstacle timing, collectible routing, and a clean finish.

## Creative Target

Retro Hop should feel like a tight cartridge-era platformer: clear silhouettes,
simple verbs, fast retries, and a level that teaches through layout rather than
text.

## Scope

In scope:

- One horizontal level
- Keyboard controls
- Run, jump, land, fall, and respawn
- Collectible gems
- Simple walking hazards
- Finish gate
- Basic HUD
- Windows development build

Out of scope:

- Multiple levels
- Menus
- save/load
- power-ups
- audio
- controller remapping
- production art pass

## Definition Of Done

- Unity project opens without compile errors.
- Level 01 exists and is included in build settings.
- Player can move, jump, collect gems, avoid or stomp hazards, recover from
  falls, and reach the finish gate.
- Windows build exists and launches.
- QA checklist records results.
- Repo and Unity project both have clean commits.
