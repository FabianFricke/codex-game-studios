# Milestone 01: First Playable

## Goal

Deliver a complete one-level Windows build of Retro Hop.

## Required Outcomes

- Design, architecture, backlog, and QA docs exist.
- Unity project opens without compile errors.
- Level 01 is generated and included in build settings.
- Player can complete the level.
- Windows build launches.
- QA checklist is completed.

## Exit Criteria

- No S1 or S2 bugs remain open.
- Build artifact exists at the documented path.
- Studio repo and Unity repo have clean commits.
