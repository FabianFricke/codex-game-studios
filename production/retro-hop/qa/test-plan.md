# Test Plan: Retro Hop

## Scope

Test one Windows build of Retro Hop with keyboard controls.

## Functional Areas

- Launch
- Player spawn
- Movement
- Jumping
- Ground collision
- Gems
- Walkers
- Kill zone
- Finish gate
- Restart
- Quit

## Release Blockers

- Crash on launch.
- Compile errors.
- Build failure.
- Player cannot finish the level.
- Player can softlock.
- Finish gate does not work.
- Repeated runtime exceptions.
- Visual roles are unreadable.
